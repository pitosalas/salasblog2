# Feature description for feature F40
## F40 — Drafts UI Polish and Admin Performance Improvements
**Priority**: Medium
**Done:** yes
**Tests Written:** yes
**Test Passing:** yes
**Description**: A set of related improvements to the admin drafts workflow and overall admin panel performance.

### Drafts page fixes
- Full draft body now displayed correctly. Root cause: `d.body` was embedded directly in a JS template literal; backticks or `${` sequences in Claude-generated text silently broke the template, causing the body and all subsequent elements (including the "Edit & Post" button) to vanish. Fixed by adding `escapeHtml()` for all dynamic HTML attributes and setting body text via `textContent` instead of innerHTML interpolation.
- "Edit & Post" button now reliably renders and links to `/admin/repost/<filename>`, opening the new-post editor pre-filled with the draft content.
- Delete draft button and endpoint (`POST /api/delete-draft`) added.
- Publish draft sets the post date to today so it appears as the newest entry.

### Stats page redesign (static pre-generation)
- Stats are now pre-generated as a static HTML file (`output/admin-stats.html`) every 60 seconds by a background scheduler job, replacing the previous per-request computation.
- Admin stats tab replaced with a zero-JS `<iframe>` pointing at the static file — zero computation on GET.
- A placeholder file is written at startup so the file always exists before the first generation completes.
- New Jinja2 template `templates/stats_page.html` renders all five time periods (Today, This Week, This Month, This Year, All Time) as pre-rendered panes with a simple JS tab switcher and no network calls.

### Non-blocking draft generation
- `generate_draft_from_drop()` (URL fetch + Claude API call) now runs in `loop.run_in_executor(None, fn)` so it no longer blocks the FastAPI event loop during the 5–10 second generation time.
- Same executor pattern applied to propose endpoints to keep the event loop free during blog-dir scans.

### Draft list performance
- Draft listing now globs `draft-*.md` only instead of scanning all 2800+ post files.

### Generated post content
- Claude prompt tightened to 50–75 words, `max_tokens=150`.
- Generated posts start with `Originally Posted on: [url](url)` prefix before the Claude paragraph.

### Config centralisation
- `config.yaml` added at project root for runtime parameters: stats refresh interval, home page post count, scheduler intervals, propose pool/count/filter settings, Claude model name.

### Test fix
- `test_pages_live_server.py` assertion corrected from `'display: none' in response.text` to `'d-none' in response.text` to match Bootstrap's CSS-class-based hiding pattern.
