# F17 — Bootstrap-First Styling

## T01 — Audit existing CSS files
**Status**: done
**Description**: Inventory all files in `static/css/`. List which rules duplicate or override Bootstrap defaults and which are genuinely site-specific.

## T02 — Add Bootstrap 5 CDN link to base template
**Status**: done
**Description**: Add `<link>` for latest Bootstrap 5 CSS and `<script>` for Bootstrap JS bundle to the base/layout Jinja2 template. Remove any locally bundled CSS framework files.

## T03 — Replace nav markup with Bootstrap navbar
**Status**: done
**Description**: Update the navigation template fragment to use Bootstrap `navbar`, `nav-link`, and `container` classes. Remove custom nav CSS.

## T04 — Replace listing pages with Bootstrap card/list components
**Status**: done
**Description**: Update blog list, raindrop list, and pages list templates to use Bootstrap `card` or `list-group` components for post entries. Remove custom list CSS.

## T05 — Replace pagination with Bootstrap pagination component
**Status**: done
**Description**: Update all paginated listing templates to use Bootstrap `pagination` / `page-item` / `page-link` classes. Remove custom pagination CSS.

## T06 — Update post detail templates with Bootstrap typography utilities
**Status**: done
**Description**: Apply Bootstrap prose/typography utilities to `blog_post.html`, `raindrop_post.html`, and `page.html`. Remove custom post-layout CSS.

## T07 — Update admin UI templates with Bootstrap forms and tables
**Status**: done
**Description**: Replace custom form and table styles in admin templates with Bootstrap `form-control`, `table`, `btn`, and `alert` classes.

## T08 — Update home page layout with Bootstrap grid
**Status**: done
**Description**: Use Bootstrap `container`, `row`, `col-*` grid classes for the home page layout. Remove custom grid CSS.

## T09 — Remove unused custom CSS
**Status**: done
**Description**: Delete or empty any CSS files in `static/css/` whose rules are now fully covered by Bootstrap. Keep only rules with no Bootstrap equivalent.

## T10 — Verify all pages render correctly
**Status**: done
**Description**: Run `uv run bg generate` and visually inspect home, blog list, blog post, raindrop list, raindrop post, pages list, a static page, 404, and admin pages. Fix any broken layout.

## T11 — Write/update rendering tests
**Status**: done
**Description**: Add or update at least one test per template group confirming that Bootstrap class names appear in rendered HTML output (e.g. `navbar`, `card`, `pagination`).
