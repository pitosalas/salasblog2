# F21 — Raindrop Collection Filtering

## Tasks

### T01 — Fetch collection from Raindrop API and store in frontmatter
**Status**: done
**Description**: Modified `format_raindrop_as_markdown()` in `utils.py` to extract `collection` title from the raindrop API response and include it in the YAML frontmatter. Added `"collection": raindrop.get("collection", {}).get("title")` alongside existing `collection_id` extraction. Raindrops already fetched from API include collection data.

### T02 — Extract unique collections during site generation
**Status**: done
**Description**: Added `extract_unique_collections(raindrops)` to `utils.py` that extracts and returns sorted collection names, filtering empty/None values. Updated `SiteGenerator.load_posts()` to include collection field in raindrop post_data. Modified `generate_listing_pages()` signature to accept collections parameter and added collections to template context for raindrops.

### T03 — Update raindrop_list.html to show collection filter links
**Status**: done
**Description**: Added collection filter button group to top of `templates/raindrops_list.html` using Bootstrap `btn-group-sm` with "All" plus individual collection links. Links point to `/raindrops/<collection-slug>/index.html` using the existing slugify filter.

### T04 — Generate collection-filtered raindrop listing pages
**Status**: done
**Description**: Added `generate_collection_filtered_pages(raindrops, collections)` method to `SiteGenerator` that generates paginated listing pages for each collection at `/output/raindrops/<collection-slug>/`. Updated `_get_page_url()` to accept optional collection_slug parameter. Integrated into generate_site() to create collection-specific pages alongside main raindrop listing.

### T05 — Slugify collection names for URLs
**Status**: done
**Description**: Created `slugify_collection()` in `utils.py` that wraps `slugify_tag()` for collection-specific slugification (lowercase, strip special chars, collapse spaces/underscores to hyphens). Registered as `slugify_collection` Jinja2 filter in generator for use in templates.

### T06 — Write tests
**Status**: done
**Description**: Created `tests/test_raindrop_collections.py` with 12 tests: 4 unit tests for `extract_unique_collections()` (sorted, empty values, missing fields, empty list), 4 unit tests for `slugify_collection()` (lowercase, spaces, special chars, hyphens), 2 template rendering tests for collection buttons, and 1 integration test for collection-filtered page generation.
