Automated Scheduler

The scheduler performs two automated tasks: Git sync to GitHub (backup content) and Raindrop sync (download new bookmarks)

Git Sync Process: /data/content → /app/content → GitHub repository
Raindrop Sync Process: Raindrop.io API → /data/content/raindrops/ → Site regeneration
Default Schedule: Git sync every 6 hours, Raindrop sync every 2 hours
Sync to GitHub Now: Immediately backup all content changes to GitHub repository
Sync Raindrops Now: Download new bookmarks from Raindrop.io and regenerate affected pages
Start Scheduler: Enable automatic syncing (Git: 6h intervals, Raindrops: 2h intervals)
Stop Scheduler: Disable all automatic background syncing operations

Safe Pages Sync

Copy pages from the Docker image (/app/content/pages) to the persistent volume (/data/content/pages)

Safe Operation: Only updates /data/content/pages/ directory
What it does: /app/content/pages → /data/content/pages
Backup: Creates automatic backup before sync
Restores: Automatically restores backup if sync fails
Sync Pages: Copies all page files and folders from GitHub content/pages to /data/content/pages
Safe: Doesn't touch blog posts, raindrops, or other content
Automatic backup: Saves existing pages as .md-old files, restored on failure
