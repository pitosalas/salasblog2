# Tasks for Feature F40

## T01 — Fix draft body not displaying fully
**Status**: done
**Description**: In `templates/admin.html` `loadDrafts()`, `d.body` was embedded directly in a JS template literal. Backticks or `${` sequences in Claude-generated text silently broke the template literal, causing the body and all following elements to not render. Fixed by: (1) adding `escapeHtml()` helper for all dynamic HTML attribute values, (2) setting body text via `bodyDiv.textContent = d.body` after building the table structure, instead of interpolating into innerHTML.

## T02 — Fix "Edit & Post" button not appearing
**Status**: done
**Description**: Same root cause as T01 — the broken template literal prevented the button cell from rendering. Once T01 was fixed the button renders correctly. Also ensured the href uses `escapeHtml(d.filename)` and links to `/admin/repost/<filename>` which opens `new_post.html` pre-filled with the draft content.

## T03 — Fix stale test using inline style instead of Bootstrap class
**Status**: done
**Description**: `tests/test_pages_live_server.py::test_pages_admin_controls_hidden_by_default` asserted `'display: none' in response.text` but the template hides admin controls via Bootstrap's `d-none` class, not inline style. Updated assertion to `'d-none' in response.text`.

## T04 — Stats page static pre-generation
**Status**: done
**Description**: Replaced per-request stats computation with a background pre-generation job. `generate_stats_cache()` renders `templates/stats_page.html` with all five time periods and writes `output/admin-stats.html` every 60 seconds via the scheduler. Admin stats tab replaced with `<iframe src="/admin-stats.html">`. A placeholder is written at startup so the file always exists. New `GET /admin-stats.html` endpoint serves the file directly.

## T05 — Non-blocking draft generation and propose endpoints
**Status**: done
**Description**: Wrapped `generate_draft_from_drop()` (URL fetch + Claude API) and propose directory scans in `loop.run_in_executor(None, fn)` to avoid blocking the FastAPI event loop during slow I/O.

## T06 — Draft list fast glob + delete endpoint
**Status**: done
**Description**: Draft listing changed from scanning all `*.md` files (2800+) to `blog_dir.glob("draft-*.md")` only. Added `POST /api/delete-draft` endpoint that removes the draft file from both `/data/content/blog/` and `/app/content/blog/`.

## T07 — Publish draft sets today's date; generated post prefix
**Status**: done
**Description**: `POST /api/publish-draft` now sets `post.metadata["date"] = date.today().isoformat()` so published drafts appear as the newest post. `draft_generator.py` prepends `Originally Posted on: [url](url)\n\n` before the Claude paragraph.

## T08 — Claude prompt shortened; config.yaml
