# Tasks for Feature F34

## T01 — Surface volume backup failures in _backup_to_volume()
**Status**: done
**Description**: In `blogger_api.py:_backup_to_volume()`, replace the silent `except` with one that logs the error AND re-raises it (or returns False and has the caller raise). The caller `blogger_newPost()` and `blogger_editPost()` should surface this as an XML-RPC fault so MarsEdit knows the post wasn't fully saved. This prevents the rsync --delete in the git sync from silently wiping a post that never made it to the volume.

## T02 — Update last_git_sync on "no changes" path
**Status**: done
**Description**: In `scheduler.py:sync_to_github()`, when `_has_git_changes()` returns False (no changes to commit), still set `self.last_git_sync = datetime.now()` before returning True. This makes the admin UI accurately reflect when the last sync check occurred, rather than showing "Never" after a successful (but no-op) sync.

## T03 — Write regression tests
**Status**: done
**Description**: Add tests covering: (1) `_backup_to_volume()` raises when the volume path is not writable — caller receives the error. (2) After a successful `sync_to_github()` call that finds no git changes, `last_git_sync` is set to a non-None value.
