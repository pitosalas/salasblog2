# F25 — Simple Visit Statistics

## Tasks

### T01 — Add VisitCounter class in stats.py
**Status**: done
Add a `VisitCounter` class in `src/salasblog2/stats.py` that persists counts to a JSON file (`/data/stats.json` in production, `stats.json` locally). Methods: `increment(path)`, `get_all()`, `get(path)`.

### T02 — Hook visit counting into server routes
**Status**: done
In `server.py`, call `get_counter().increment(path)` on GET requests for: `/` (home), `/raindrops/{file_path}` (link blog listing and individual posts), and `/pages/{file_path}` (static pages). Only count HTML responses, not HEAD requests.

### T03 — Add /admin/stats route
**Status**: done
Add a GET route `/admin/stats` in `server.py` that is authentication-protected and renders visit counts using `admin_stats.html`.

### T04 — Create admin_stats.html template
**Status**: done
Create `templates/admin_stats.html` with a Bootstrap table showing path → visit count, sorted by count descending, with a total count summary.

### T05 — Write tests in test_stats.py
**Status**: done
Add 9 tests in `tests/test_stats.py` covering: increment, multiple increments, persistence to file, loading from file, get_all sorting, empty file handling, and independent path counts.
